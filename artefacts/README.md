# Artefacts

Stage caches written by the pipeline. They are regenerated by the commands in the main README and are not
committed, except for the small reports below.

| path | written by | contents |
|---|---|---|
| `train/`, `test/` `s{1,2,3}.parquet` | `run --stage normalize` | cleaned records (name views, canonical address, postal / numbers / landmarks) |
| `train/`, `test/` `emb_s1.npy`, `emb_pool.npy` | `run --stage embed` | fine-tuned e5-small embeddings (disk memmaps) |
| `train/`, `test/` `cands.parquet`, `query_idx.parquet` | `run --stage block` (or `restore_cands` for test) | candidate pairs as integer indices |
| `train/`, `test/` `feats/part_*.parquet` | `run --stage features` | pair features in S1 chunks |
| `train/oof.parquet`, `test/probs_<model>.parquet` | `run --stage rank` | level-1 OOF / test probabilities |
| `embed_ft/` | `finetune_embed` | fine-tuned encoder checkpoint |
| `model*/` | `run --stage rank` | LightGBM fold models + `config.json` (features, decision) |
| `splits/` | `splits` | fit / dev / lockbox S1 lists; **`splits.json` committed** |
| `exp/<tag>/` | `loop_eval` | stacker probabilities, dev / lockbox matches; **`report.json` committed** |
| `exp/E001_mylgbm/final_test_probs.parquet` | `loop_eval --final` | final stacker test probabilities (input of the v14 rescue step) |
